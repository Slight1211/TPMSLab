# TPMSLab 0.3.1

English runtime messages for generate(), Config validation, build_mph(), and the local web API. Exported report warnings are also English. The web page's bilingual interface and historical validation files are retained.

The numerical algorithms, configuration keys, mesh arrays and COMSOL physics settings are unchanged. This patch changes runtime source bytes, so its hashes are recorded separately in runtime_hashes_0.3.1.json. The 0.3.0 scientific baseline and its checksums remain intact. Exception classes are unchanged, but message text has changed.

Install the local wheel with `python -m pip install tpmslab-0.3.1-py3-none-any.whl`. PyPI 0.3.0 and the published v0.3.0 tag are not overwritten. Do not claim that 0.3.1 has been published until the release is confirmed.
